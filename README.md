# 配料表体检

用手机拍食品包装上的配料表，逐项标出推荐、一般、注意、少吃，给出健康分，并单独评估**适不适合给 4 岁儿童吃**。

在线使用：https://mingxintan-coder.github.io/food-label-check/

- 拍照后在手机浏览器本地识别文字（Tesseract.js），照片不上传
- 也可以直接粘贴配料表文字（iPhone 相机的「实况文本」识别更准）
- 儿童标准参考《中国学龄前儿童膳食指南（2022）》

评分只看配料表本身，仅供参考，不能替代医生或营养师的建议。
